# Pure Spoiler Blocker — Privacy Policy

_Last updated: November 12, 2026_

Pure Spoiler Blocker is a browser extension that hides possible spoilers for games, shows, films and anime (by default for GTA VI) on web pages. It works entirely inside your browser.

## What we collect

**Nothing.** Pure Spoiler Blocker does not collect, sell or share any personal data. We have no servers that receive your data, no analytics, no telemetry, no advertising and no third-party tracking code.

## What the extension can access

- **YouTube, Reddit and X (Twitter) by default.** On these sites it reads the text of the page (titles, descriptions, comments, labels) inside your browser to decide what to blur.
- **Google, TikTok and Instagram — only if you press "Turn on there too":** your browser asks you once to allow these sites. Then the same check runs there. You can remove the access at any time in the browser's extension settings.
- **Every site, only if you turn "Protect every site" on:** your browser asks you to allow access to all websites. Then the same check runs on every site you open. You can switch it off at any time; the access can also be removed in the browser's extension settings.
- It does not read passwords or form fields, does not see your browsing history, and does not store anything about the pages you visit. Blocks that contain a text field or editor are never covered.

## What stays on your device

- Your settings (on/off, the titles and words you protect and their level and dates, folded comments, paused time, sites where it is off, "protect until" date, trusted and always-hidden authors). Words you hide with the right-click menu are saved the same way.
- A counter of how many blocks were hidden in total (a number only).
- A counter of blocks hidden this week (a number and the Monday of that week, nothing else).
- Whether you already saw the review request.
- All of this is in the browser's local extension storage and is removed together with the extension.

## Network requests

The extension makes **no network requests**. The code contains no way to send data (no fetch, no XMLHttpRequest, no WebSocket, no beacon), and every version is checked for the usual ways of sending data (an automatic code check plus a test that watches the network while the extension runs). Such checks can miss an unusual trick, so the source code is public for you to read. Earlier versions (up to 1.3) checked a paid license with Gumroad; that feature and its permission were removed in 1.4, and any old license data is deleted from your device when the extension updates.

The source code is open to read: https://github.com/qwemort/pure-spoiler-shield

## Things you share yourself

- **Spoiler link, list code, week picture** ("Share" and "Advanced" in the window) are only copied to your clipboard, or saved as a file. The extension uploads nothing. The spoiler link keeps the text after the `#` of the address, which a browser never sends to a server.

## Reports you send yourself

- **"Not a spoiler? Report"** (right-click menu) copies a short report (list name, site, extension version and the text of the block you clicked) to your clipboard and opens a GitHub issue page in a tab with a fixed hint text; no page text is put there. The page text is not put into the address. Nothing is published until you paste it, read it and press "Submit" on GitHub yourself; you can edit or delete any part first. GitHub's privacy policy applies to what you publish there.
- **"Copy a report"** (shown only when a site seems to have changed its layout) copies numbers only — version, site, how many cards and links were found, how many blocks were hidden — to your clipboard. No page text.
